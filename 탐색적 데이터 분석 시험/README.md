# 분석 내용

## 1. 데이터 기초 특성 파악

* 데이터 불러오기
* 데이터 크기(shape) 확인
* 데이터 타입(dtypes) 확인
* 기술통계량(describe) 확인
* 수치형 변수와 범주형 변수 분리
* 범주형 변수의 빈도 확인(value_counts)

### 목적

* 데이터 구조 이해
* 변수의 특성 파악
* 결측치 및 이상 여부 확인

---

## 2. 단변량 분석

### 히스토그램(Histogram)

다음 수치형 변수의 분포를 확인하였다.

* 월평균구매금액
* 구매횟수

확인 내용

* 데이터의 분포 형태
* 왜도(Skewness)
* 치우침 여부
* 이상 구간 존재 여부

---

### Count Plot

범주형 변수의 빈도를 확인하였다.

예시

* 성별
* 거주지역
* 쿠폰사용여부

확인 내용

* 범주별 데이터 개수
* 데이터 불균형 여부

---

## 3. 상관관계 분석

수치형 변수 간 Pearson 상관계수를 계산하고 Heatmap으로 시각화하였다.

분석 대상 예시

* 나이
* 월평균구매금액
* 구매횟수
* 리뷰점수

### 분석 결과

* 구매횟수와 월평균구매금액은 양(+)의 상관관계를 보였다.
* 리뷰점수와 구매 관련 변수는 상대적으로 낮은 상관관계를 보였다.
* 대부분의 변수는 매우 높은 상관관계를 보이지 않아 다중공선성의 위험은 크지 않은 것으로 판단된다.

> **상관관계는 변수 간의 관련성을 의미할 뿐 인과관계를 의미하지 않는다.** 따라서 한 변수의 변화가 다른 변수의 원인이라고 단정할 수는 없다.

---

## 4. 범주형 변수와 수치형 변수 비교

Boxplot을 이용하여 범주형 변수에 따른 수치형 변수의 분포를 비교하였다.

예시

* 성별별 구매금액
* 거주지역별 구매금액
* 쿠폰사용여부별 구매금액

또한 GroupBy를 이용하여 그룹별 평균 및 통계량을 비교하였다.

---

## 5. 그룹별 비교 분석

GroupBy와 Pivot Table을 활용하여 그룹별 구매 특성을 분석하였다.

예시

* 거주지역별 평균 구매금액
* 성별 평균 구매금액
* 쿠폰사용여부별 구매 특성

막대그래프를 이용하여 그룹 간 차이를 시각적으로 비교하였다.

---

# 데이터 분석 인사이트

### 1. 구매횟수가 높은 고객은 중요한 고객군이다.

구매횟수와 구매금액이 양의 상관관계를 보이므로 기존 고객의 재구매를 유도하는 것이 매출 증가에 효과적일 수 있다.

활용 방안

* 멤버십 운영
* 적립금 제공
* 재구매 쿠폰 발급

---

### 2. 리뷰점수만으로 구매를 설명하기는 어렵다.

리뷰점수와 구매 관련 변수의 상관관계가 높지 않다면 리뷰 관리만으로 구매를 크게 증가시키기는 어려울 수 있다.

활용 방안

* 가격 할인
* 맞춤형 추천
* 프로모션
* 쿠폰 마케팅 병행

---

### 3. 지역별 맞춤형 마케팅이 가능하다.

거주지역별 평균 구매금액의 차이가 존재한다면 지역 특성에 맞는 마케팅 전략을 수립할 수 있다.

예시

* 지역별 이벤트
* 지역별 프로모션
* 지역별 상품 추천
