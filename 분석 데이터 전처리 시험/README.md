## 수행 내용

### 1. 결측치 처리

#### 수치형 변수
- 결측치 확인
- 중앙값(Median) 대체
  - 나이
- 평균(Mean) 대체
  - 리뷰점수

#### 나이
- 중앙값(Median)으로 결측치를 대체하였다.
- 나이는 이상치의 영향을 받을 가능성이 있으므로 평균보다 중앙값이 대표값으로 적합하다.

#### 리뷰점수
- 평균값(Mean)으로 결측치를 대체하였다.
- 리뷰점수는 일정한 범위 내에서 분포하는 연속형 데이터이므로 평균이 전체 데이터를 대표하기에 적합하다.

#### 범주형 변수
- 최빈값(Mode)으로 결측치 대체

#### 결측치 처리 기준

|변수 종류|처리 방법|
|---|---|
|수치형|평균 또는 중앙값|
|범주형|최빈값|

---

### 2. 이상치 처리

#### Boxplot 시각화

- 월평균구매금액 변수의 이상치 확인

#### IQR(사분위수 범위) 기법 사용

계산 과정

- Q1
- Q3
- IQR
- Lower Bound
- Upper Bound

#### 처리 방법

이상치를 제거하지 않고 **Capping(경계값 대체)** 을 수행하였다.

선택 이유

- 데이터 손실 방지
- 표본 수 유지
- 극단값의 영향 감소

---

### 3. 범주형 변수 인코딩

#### One-Hot Encoding

적용 변수

- 쿠폰사용여부

선택 이유

- Y/N 두 개의 명목형 변수
- 범주 간 순서가 존재하지 않음
- 모델이 순서를 학습하는 것을 방지

```python
pd.get_dummies()
```

---

#### Label Encoding

적용 변수

- 거주지역

선택 이유

- 문자열 데이터를 숫자로 변환
- 차원 증가 방지
- 트리 기반 모델에서 효율적으로 사용 가능

```python
pd.factorize()
```

---

### 4. 파생변수 생성

다음과 같은 파생변수를 생성하였다.

|변수|생성식|
|---|---|
|ratio|구매횟수 / 리뷰점수|

파생변수를 생성하여 고객 구매 특성을 더욱 효과적으로 분석할 수 있도록 하였다.

---

### 5. 데이터 스케일링

Min-Max Scaling을 적용하였다.

사용 클래스

```python
MinMaxScaler()
```

적용 대상

- 수치형 변수

목적

- 변수 간 스케일 차이 제거
- 머신러닝 모델 성능 향상
- 0~1 범위로 정규화

## 전처리 과정

```
데이터 불러오기
        │
        ▼
결측치 확인 및 처리
        │
        ▼
이상치 탐지(Boxplot)
        │
        ▼
IQR 계산
        │
        ▼
Capping 처리
        │
        ▼
범주형 변수 인코딩
        │
        ▼
파생변수 생성
        │
        ▼
Min-Max Scaling
        │
        ▼
전처리 완료
```
